# Notes List

Android-приложение для управления списком заметок, демонстрирующее применение современных архитектурных подходов и инструментов экосистемы Jetpack.

## Стек технологий

- **Язык:** Kotlin
- **UI:** Jetpack Compose, Material 3, View Binding
- **Архитектура:** MVVM
- **Хранение данных:** Room Database, DataStore Preferences
- **Внедрение зависимостей:** Dagger 2
- **Навигация:** Jetpack Navigation Component (Safe Args)

## Ключевые особенности

- Реактивное управление состоянием UI через ViewModel.
- Асинхронная работа с локальной базой данных и типобезопасная навигация.
- Масштабируемая и тестируемая структура кода благодаря внедрению зависимостей.
